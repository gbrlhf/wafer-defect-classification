Supervised Defect Classification

Kirimkan pengukuran wafer untuk mengklasifikasikan jenis atau status defect menggunakan model terlatih.

Input Fitur Pengukuran Wafer
Dynamic Schema
Catatan Struktur Fitur: Nama fitur spesifik dan skala nilai akan disinkronkan secara otomatis setelah proses Exploratory Data Analysis (EDA) pada Google Colab selesai. Input di bawah ini merupakan form inspeksi interaktif yang siap terhubung dengan REST API backend.
Workflow Klasifikasi
  1. User menginputkan parameter fitur fisik/elektrikal wafer.
  2. Frontend membungkus data ke JSON payload dan memanggil POST /api/classification/predict.
  3. FastAPI memvalidasi payload melalui skema Pydantic.
  4. Model Service menjalankan classifier.joblib hasil pelatihan Google Colab.
  5. Hasil prediksi kategori defect dan probabilitas dikembalikan ke UI.
Model Serialization:
