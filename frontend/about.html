Wafer Defect Classification System

Aplikasi web Machine Learning ini dirancang khusus untuk industri manufaktur semikonduktor guna mendeteksi serta mengklasifikasikan anomali dan cacat pada wafer silikon. Melalui integrasi model berbasis AI, teknisi dapat mendeteksi kegagalan proses fabrikasi lebih awal sehingga efisiensi produksi meningkat.

Metodologi Machine Learning:
Supervised Learning
Klasifikasi multi-kelas untuk memprediksi label defect spesifik (misal: Center, Donut, Edge-Ring, Loc, Scratch) menggunakan Scikit-learn classifier.
Unsupervised Learning
Clustering tanpa label untuk mengelompokkan pola sebaran die cacat pada wafer dan mengeksplorasi cluster anomali baru yang belum terpetakan.
Technology Stack
