# Semiconductor Wafer Defect Dataset

Direktori ini digunakan untuk menyimpan metadata, dokumentasi skema, dan file placeholder dataset semiconductor wafer.

## Sumber Dataset
- **Nama Dataset:** Semiconductor Wafer Defect Classification Dataset
- **Sumber:** Kaggle
- **Kategori:** Manufaktur Semikonduktor, Quality Assurance, Computer-Aided Inspection

## Kebijakan Data (Data Policy)
1. **Dilarang melakukan commit dataset berukuran besar ke repository GitHub.** File raw dataset (`.csv`, `.zip`, `.parquet`, dll.) telah diatur pada `.gitignore`.
2. Eksplorasi Data Awal (EDA) dan pembersihan data dilakukan langsung pada environment **Google Colab**.
3. File sampel kecil yang telah di-anonimisasi dapat ditempatkan di sini hanya jika diperlukan untuk testing fungsional.
4. Definisi kolom fitur dan label target final akan didokumentasikan di sini setelah proses analisis dan seleksi fitur di Google Colab selesai.
